# freshrss-cli

A command-line client for [FreshRSS](https://github.com/FreshRSS/FreshRSS) over its Google Reader API. It manages subscriptions, categories and tags, reads items and marks them read or starred, from any machine that can reach the server. Every command prints JSON on stdout, so it works the same for a person and for a script or an AI agent.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/TakashiAihara/freshrss-cli/main/install.sh | sh
```

This puts a single `freshrss` binary (Linux or macOS, amd64 or arm64; no runtime needed) in `~/.local/bin`. `FRESHRSS_INSTALL_DIR` and `FRESHRSS_VERSION` change where and which release.

From a clone, with Bun: `bun install && bun run install-bin`.

## Configure

Enable the API on the server (Administration → Authentication → "Allow API access") and set an API password for your user (Profile → API management). The API password is not the web login password.

```bash
export FRESHRSS_URL=https://freshrss.example.net   # without /api/greader.php
export FRESHRSS_USER=alice
export FRESHRSS_API_PASSWORD=...                    # read from the environment only
```

`--url` and `--user` override the first two.

## Use

```bash
freshrss subs list
freshrss subs add https://example.net/feed.xml --category News
freshrss entries --unread -n 50
freshrss entries --label News --all
freshrss mark read 'tag:google.com,2005:reader/item/0006421a5b8f3c20'
freshrss mark-all-read user/-/label/News
freshrss subs export > subscriptions.opml
```

Every command, option and output shape is listed in [docs/design.md](docs/design.md).

Exit codes: 0 success, 1 the server refused or failed (its message is on stderr), 2 usage or configuration error.

## What the API cannot do

- Create or change XPath / JSON scraping feeds' settings. Make them in the web UI; `subs export` / `subs import` carry them as OPML.
- Manage users or server settings.

## Development

```bash
bun install
bun test            # starts a throwaway FreshRSS in Docker
bun run typecheck
bun run lint
```

The HTTP client in `src/generated/` is generated by Orval from `openapi/greader.yaml`, which is written by hand from FreshRSS's `p/api/greader.php` (FreshRSS publishes no OpenAPI document). Regenerate with `bun run generate`.
